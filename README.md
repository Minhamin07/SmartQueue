# 🏥 Smart Queue – Hospital Management System

## 📌 About the Project

Smart Queue is a web-based hospital queue management system designed to streamline patient flow and reduce waiting time. It helps manage hospital queues through a digital platform, making the process more organized and convenient for patients and hospital staff.

## ✨ Key Features

- Digital Queue Management
- Patient Information Management
- Queue Status Monitoring
- Hospital Staff Dashboard
- Organized Patient Flow
- Reduced Manual Queue Handling

## 🛠️ Technology Stack

| Category | Technologies |
|---|---|
| Frontend | Html, Css, JavaScript |
| Backend | Python, Django |
| Database | MySQL |

## 📦 Main Modules

1. Patient Management
2. Staff Management
3. Queue Management
4. Token Management
5. Queue Status Tracking
6. Dashboard Management

## 🔄 Application Workflow

1. Patient information is registered in the system.
2. A queue token is generated.
3. Patients are organized in the queue.
4. Hospital staff monitor and manage the queue.
5. Queue status is updated as patients are attended.

## 🎯 Project Objective

To improve hospital queue management by providing a digital solution that helps reduce waiting time, organize patient flow and simplify hospital operations.
